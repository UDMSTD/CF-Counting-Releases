# CF Counting

Windows 10 / 11 x64 克隆形成计数工具，支持六孔板和 T12.5 培养瓶图像。

[下载安装包](https://github.com/UDMSTD/CF-Counting-Releases/releases/latest)

- 本地分析、ROI 编辑、结果导出。
- `.cfcproj` 工程保存与恢复。
- 深色、浅色及 Arona × Plana 外观。
- 从 GitHub 获取更新，错误记录由用户手动导出为本地文件。

这个仓库只提供安装包、校验文件和发行说明。分析图像与工程保存在本机。

安装包位于 Releases；`Source code` 下载项仅包含本仓库的发行资料。
